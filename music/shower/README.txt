Songs for shower.

Option A – keep numbers:
  1.mp3  2.mp3  3.mp3  4.mp3  5.mp3

Option B – name the files after the song:
  Perfect.mp3
  Soft Night.mp3
  …

Then edit phone/src/audio/music.ts and set both name + file, e.g.:

  { name: 'Perfect', file: '/music/shower/Perfect.mp3' },

The `name` is what she sees in the song picker.
